shopcn is open-source, and making sure it can be deployed anywhere is a priority. So, each component used in shopcn is easy to deploy and use. Following is the basic tech stack used in shopcn:

## Backend

- [Hono](https://hono.dev/)
- [tRPC](https://trpc.io/)
- [PostgreSQL](https://www.postgresql.org/)
- [Drizzle ORM](https://orm.drizzle.team/)
- [BetterAuth](https://better-auth.com/)
- [Stripe](https://stripe.com/)

## Frontend

- [TanStack Start](https://tanstack.com/start/latest/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [TRPC Client](https://trpc.io/docs/client/react)

## CLI

- [TypeScript](https://www.typescriptlang.org/)
- [Commander.js](https://www.npmjs.com/package/commander)
- [tRPC Client](https://trpc.io/docs/client/react)
- [tsup](https://www.npmjs.com/package/tsup)

## Documentation

- [Fumadocs](https://fumadocs.com/)
- [Next.js](https://nextjs.org/)
